# bergmandavid.com

Static personal site for David Bergman, deployed with GitHub Pages.

The page uses plain HTML and CSS with a self-hosted Mozilla Text font. No build step or JavaScript is needed.

Run locally with `python3 -m http.server 8000`.

GitHub Pages publishes the root of `main` to `bergmandavid.com`. The weekly photo is `assets/photo-of-the-week.jpg`, and the resume is `assets/David_Bergman_Resume.pdf`.
